# April Aely

**AI Product Engineer · Applied AI, Product & Technology Leader · Founder, Peachity**

I design and build AI-native products, from product architecture and data modeling through full-stack implementation, integrations, and deployment. My work connects AI capabilities to persistent context, clear decision-making, and production-ready systems.

My commercial product repositories are private because they contain proprietary code and product IP. This public portfolio documents implemented architecture and engineering decisions, alongside a standalone working code showcase built from scratch with synthetic data.

## What I Build

- **AI-native SaaS and agentic workflows:** specialized capabilities, model orchestration, structured outputs, persistent company and relationship intelligence, and human approval for consequential actions.
- **Full-stack product systems:** React, Next.js, TanStack, TypeScript, Supabase/Postgres, and Vercel-oriented deployment.
- **Connected software:** provider adapters, APIs, OAuth, Stripe billing, Resend email, and MCP interfaces.
- **Reliability around AI:** Zod validation, deterministic decision logic, test suites, access boundaries, rate limiting, product analytics, and observability instrumentation.

My repositories include implementations using OpenAI and Anthropic, with development adapters that allow workflows to be exercised independently of live accounts.
